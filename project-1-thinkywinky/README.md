## 🎯 Overview

**Thinky Winky** is an all-in-one productivity and study management web app built for students. It combines schedule planning, focus techniques (Pomodoro), progress analytics, and course-material sharing into a single dashboard — helping students organize their study routine and track how they spend their time.

The goal was to solve a problem I kept running into as a student myself: study tools tend to be scattered across different apps (a calendar app, a timer app, a file-sharing app). Thinky Winky merges all of that into one place.

---

## ✨ Key Features

### ⏱️ Interactive Pomodoro Focus Timer
Customizable work/break intervals, linked directly to subjects, with automatic logging of completed sessions to track total study time.

### 📅 Weekly Study Planner & Interactive Calendar
Plan sessions with start times, durations, and notes. Monthly/daily calendar views with real-time task-completion tracking.

### 📄 Course Summaries & PDF Document Hub
Upload and organize PDF study summaries by subject, with file validation and a download counter.

### 📊 Progress Analytics & Visual Stats
Charts and breakdowns showing total focus time, sessions completed, and time distribution across modules.

### 💡 Study Techniques Guide
Built-in guides explaining proven study methods: Pomodoro, Feynman Technique, Active Recall, SQ3R, and the Leitner System.

### 👤 Secure Authentication & Profiles
Account signup/login with hashed passwords, plus profile customization (study field, avatar).

## 🧠 A Key Challenge

One interesting problem I solved: linking Pomodoro sessions in real time to specific modules/subjects so that analytics (time spent per module, daily/weekly trends) update automatically without the user manually logging anything — the timer's AJAX endpoint logs each completed session directly to the database, which then feeds the progress dashboard.
